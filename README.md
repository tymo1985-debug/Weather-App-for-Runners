# Погода для бега — PWA

Прогноз погоды с оценкой условий для бега: 0–100 баллов, лучшее окно дня,
разбор факторов, качество воздуха и пыльца, радар осадков.

## Что уже работает

| Экран | Файл / функция |
|---|---|
| Главная: текущая погода, оценка, полоса часов и дней | `renderHome`, `renderStrip` |
| Почасовой прогноз с оценкой и разбором лучшего окна | `renderHourly` |
| 10 дней с переключателем «температура / осадки / оценка» | `renderDaily` |
| Разбор условий: кольцо, график дня, вклад факторов, таймлайн | `renderAnalysis` |
| Карточка фактора со шкалой и объяснением | `openFactorSheet` |
| Воздух и пыльца, переключатель учёта пыльцы | `renderAir` |
| Радар осадков с проигрыванием кадров | `initRadar` |
| Детали погоды, профиль бегуна, список городов | `renderDetails` |

## Как запустить

Нужен любой HTTP-сервер — сервис-воркер и модули не работают через `file://`.

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для установки на телефон нужен HTTPS: подойдёт GitHub Pages, Netlify,
Vercel или Cloudflare Pages — просто выложите папку как есть, сборка не нужна.

## Данные

- Погода и качество воздуха: [Open-Meteo](https://open-meteo.com) — без ключа и регистрации.
- Поиск городов: Open-Meteo Geocoding. Обратный геокодинг: BigDataCloud.
- Радар: [RainViewer](https://www.rainviewer.com), подложка карты — CARTO / OpenStreetMap, Leaflet.

## Как считается оценка

Каждый фактор даёт 0–100 баллов, затем берётся взвешенная сумма
(`WEIGHTS` в `js/engine.js`):

| Фактор | Вес | Что считает |
|---|---|---|
| Температура | 30 | Коридор комфорта по ощущаемой температуре, сдвигается профилем |
| Осадки | 22 | Вероятность и интенсивность, берётся худшее из двух |
| Ветер | 12 | Штраф начинается с 9 км/ч |
| Воздух | 12 | Европейский индекс качества воздуха |
| Влажность | 10 | Комфорт 35–62% |
| УФ | 8 | Штраф с индекса 2,5 |
| Покрытие | 6 | Дождь за последние 4 часа и риск наледи |
| Пыльца | 8 | Только если включена в профиле |

Дальше итог смещается к худшему фактору (80/20), чтобы одно плохое
условие не тонуло в среднем. Отдельные ограничители: гроза — не выше 30,
мокрая дорога около нуля — не выше 52.

Профиль бегуна (переносимость жары и холода, отношение к дождю,
чувствительность к воздуху, длительность пробежки) меняет и пороги
факторов, и длину окна, которое ищет приложение.

## Что стоит добавить дальше

- Push-уведомление утром с лучшим окном на день.
- Сравнение нескольких городов на одном экране.
- Учёт маршрута: тень, набор высоты, близость к дорогам.
- Синхронизация с трекером, чтобы оценка училась на ваших реальных пробежках.
